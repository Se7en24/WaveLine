# 🚢 WaveLine – Cargo Shipment Management System

WaveLine is a lightweight **Node.js + Express + MongoDB** application designed to help logistics operators manage cargo records from creation to delivery. It provides a simple local shipping-management workflow where the admin can add shipments, update statuses, track progress, and remove completed entries.

---

## 🚀 Features

### 🔹 Cargo Management
- Add new cargo with details such as sender, receiver, weight, cargo type, and destination  
- Edit and update any shipment information  
- Delete cargo entries when completed or cancelled  

### 🔹 Shipment Tracking
- Assign each shipment a unique tracking ID  
- Update shipment status across multiple stages  
  - Booked  
  - In Transit  
  - Arrived at Hub  
  - Out for Delivery  
  - Delivered  

### 🔹 Admin Dashboard
- View all shipments in one place  
- Search by shipment ID, name, or destination  
- Filter shipments based on their status  

### 🔹 Local & Offline Ready
- Runs fully on **localhost**  
- Uses **MongoDB local database**  
- No internet required for operation
